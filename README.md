# Simulating Concepts of Physics in Python using Numerical Methods

Hi everyone! Me and my partner have teamed up to produce codes that numerically simulate some basic concepts of physics like:
 - **Classical Mechanics**
  - Simple and Damped Harmonic Motion
  - Simple Pendulum
  - Orbital Motion
  - Collisions
- **Electromagnetism**
  - A field solver for a dipole system
  - A charge particle trajectory tracker
  - A Lorentz force simulator
  - one more UPDATE THIS!
  - Double slit experiment
- **Quantum Mechanics**
  - 1-D Quantum Harmonic Oscillator
  - Quantum tunnelling through potential wells and barriers

In each code, we have plotted the analytic solution (whenever possible), as well as the numerically solved solution, and have also tried to make animations for real systems wherever possible!
